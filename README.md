# TTL-Based Aerospace Cabin Safety Logic Controller

A TTL-based aerospace cabin safety monitoring system designed using 7400-series logic gates. The project simulates aircraft cabin operational conditions and provides safe, warning, and emergency indications using combinational logic circuits and LED outputs.

## Features
- Aerospace-inspired safety monitoring
- LED-based safety indication
- Combinational logic implementation
- Proteus simulation included
  
## Components Used
- 7408 AND Gate
- 7432 OR Gate
- 7404 NOT Gate
- LEDs
- Switches
- Breadboard
- 5V Supply

## Software Used
- Proteus Design Suite

## Output Indicators
- Green LED → Safe
- Yellow LED → Warning
- Red LED → Emergency
